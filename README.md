# Well Done Data

## Project Overview
This repository contains our team's collaborative data analytics project for Clemson University.

We are using the Ames Housing dataset to explore housing characteristics and build a multiple regression model to predict home sale prices.

## Repository Structure
- `data/` — Contains the AmesHousing.csv dataset.
- `notebooks/` — Contains Jupyter notebooks for data exploration and regression analysis.
- `results/` — Stores charts, model outputs, and other results.
- `requirements.txt` — Lists the Python packages required to run the project.

## Project Objectives
1. Explore the Ames Housing dataset and generate descriptive statistics.
2. Create visualizations to better understand the data.
3. Build a multiple regression model to predict `SalePrice` using multiple housing characteristics.
4. Ensure all notebooks can run on different computers.

## Getting Started
1. Download or clone this GitHub repository.
2. Open a terminal in the repository's main folder.
3. Install the required Python packages:

   `pip install -r requirements.txt`

4. Open the Jupyter notebooks in the `notebooks/` folder.
5. Run the notebook cells in order.
